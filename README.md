# 🩺 VitalTrack – Health Tracker

VitalTrack is a modern, responsive health tracking web application designed to help users monitor their fitness, nutrition, workouts, and overall wellness. The application provides a clean Apple Health-inspired interface that works seamlessly on desktop, tablet, and mobile devices.

---

## ✨ Features

### 🔐 Authentication
- Sign In & Sign Up
- Guest Login
- Show/Hide Password
- Logout

### 🏠 Dashboard
- Daily Activity Rings
- Steps Tracker
- Heart Rate Monitoring
- Calories Burned
- Water Intake
- Weekly Statistics
- Recent Activities

### 🍎 Nutrition
- Daily Calorie Tracker
- Nutrition Overview
- Macronutrient Progress
- Meal History
- Micronutrient Tracking
- Add Meal

### 💪 Workouts
- Workout History
- Daily Steps Chart
- Calories Burned
- Exercise Statistics
- Weekly Progress
- Add Workout

### 👤 Profile
- Personal Information
- BMI & Health Metrics
- Goal Progress
- Heart Rate Chart
- Account Settings
- Notification Settings
- Connected Devices

### 📱 Responsive Design
- Desktop Sidebar Navigation
- Mobile Bottom Navigation
- Slide-Out Mobile Menu
- Fully Responsive Layout
